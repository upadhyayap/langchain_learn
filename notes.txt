Agents - LangChain agents are autonomous AI systems that can perform complex tasks by breaking them down into smaller steps. They use a combination of tools (like search, calculator, or custom functions) and an LLM to decide which actions to take. Agents can:
1. Plan and execute multi-step tasks
2. Use tools to interact with external systems
3. Make decisions based on context and available tools
4. Adapt their approach based on intermediate results
you can chain agents and hook them up with the LLM to perform a complex task.


Tools - LangChain tools are functions that agents can use to interact with external systems or perform specific tasks. They can be:
1. Built-in tools (like search, calculator, or web browser)
2. Custom tools created by wrapping your own functions
3. Tools that integrate with external APIs and services
Tools are essential components that enable agents to perform real-world actions beyond just generating text.

outputparsers - LangChain output parsers are utilities that help structure and format the raw text output from LLMs into more usable formats. They can:
1. Convert text into structured data types (like JSON, lists, or custom objects)
2. Extract specific information from LLM responses
3. Format outputs according to predefined schemas
4. Handle parsing errors and provide fallback options
Common parsers include StrOutputParser, JSONOutputParser, and PydanticOutputParser. They are essential for making LLM outputs more predictable and easier to work with in applications.

Prompt
A prompt can be broken down into 4 components
- Instructions
    - Which tasks needs to be performed
    - sets the stage for the model response
- context
    - Additional information to fine tune the instructions
- Input data
    - data that the model needs to process
- output Indicators

Zero shot prompting -  is a technique where we provide the model with a task without any examples or demonstrations. The model relies solely on its pre-trained knowledge to understand and complete the task. For example, "Translate this English text to French: 'Hello, how are you?'" or "Summarize the following article in three bullet points: [article text]". This approach is simple but may not always yield the most accurate results compared to few-shot or many-shot prompting.

Few shot prompting - is a technique where we provide the model with a few examples of the desired input-output pairs before asking it to perform the task. These examples help the model understand the expected format and style of the response. For instance, if we want the model to classify sentiment, we might show it a few examples like "I love this movie" → positive, "This was terrible" → negative, before asking it to classify new text. This approach typically yields better results than zero-shot prompting as it gives the model concrete patterns to follow.

chain of thought prompting - is a technique where we ask the model to break down its reasoning process step by step before arriving at the final answer. This helps the model think through complex problems more carefully and often leads to more accurate results. For example, instead of directly asking "What is 25% of 80?", we might prompt "Let's solve this step by step: First, what is 25% as a decimal? Then, how do we multiply that by 80? Show your work." This approach is particularly useful for mathematical problems, logical reasoning, and complex decision-making tasks.

ReAct Prompting (Reason + Act) is a prompting technique that combines reasoning and action-taking in a step-by-step format. It helps models break down complex tasks by alternating between thinking (reasoning) and doing (acting). For example:

Question: "What is the weather in New York and should I bring an umbrella?"

ReAct Response:
Thought: I need to check the current weather in New York to determine if an umbrella is needed.
Action: Search for "current weather New York"
Observation: Current temperature is 72°F with 60% chance of rain
Thought: Since there's a high chance of rain, an umbrella would be useful
Action: Recommend bringing an umbrella
Final Answer: Yes, you should bring an umbrella to New York today as there's a 60% chance of rain despite the mild temperature of 72°F.

This structured approach helps models make more informed decisions by explicitly separating the reasoning process from actions.

mcp server - A Model Control Protocol (MCP) server is a specialized server that manages and coordinates interactions between language models and various tools or services. It acts as a middleware layer that:
1. Handles model requests and responses
2. Manages tool execution and integration
3. Provides a standardized interface for model-tool communication
4. Enables secure and controlled access to external systems
MCP servers are crucial for building robust AI applications that require reliable model-tool interactions.
